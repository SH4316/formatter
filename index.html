A few good things to know

Choose a format explicitly. File uploads select the format by extension when recognized. Line width is a formatting target, rather than a hard limit: long strings, URLs, and syntax rules may extend beyond it.

Select Format or Compact JSON to replace the code in the editor with the result. If formatting fails, your code stays unchanged. Copy and Download use the current editor contents. Ctrl+Enter or ⌘+Enter also formats your code.

JSON sorting preserves large number literals, duplicate keys, and array order. XML defaults to preserving text whitespace; Reindent all can change whitespace in mixed content. SQL formatting does not validate query correctness. Inputs are limited to 1 MiB.
